# Phase K 本机试验

从项目根目录启动 `.venv/bin/python -m streamlit run Agent/web_app.py --server.address 127.0.0.1 --server.port 8514`。选择 Phase K。数据使用确认允许本轮读取，单独勾选付费确认才会启动 Qwen。保留标准和 Phase H 选项。

在平台及供应商处理范围已核实后，由本机配置管理员在私有的 `Agent/config/research_access.json` 中记录真实的扩容授权。保留原有有效期及处理条款，补充以下对象。不要提交实际配置或凭据。

```json
"phase_k_scope": {
  "approved": true,
  "approval_reference": "此处必须填写实际扩容授权记录的引用",
  "videos": 20,
  "comments_per_video": 50,
  "model_comments": 80
}
```

没有适用记录时，Phase K 的采集和分析均禁用。网页复选框只确认本轮使用，不替代授权记录。

每轮只取一页搜索及每个保留视频的第一页顶层评论。最多 20 个候选视频，同频道最多保留两个，标题高度相似的结果剔除。筛选时间是视频发布时间。官方 API 项目配额在启动前由管理员核对。网络读取最多使用现有的一次暂时故障重试；Qwen 无自动重试。

模型最多 20 次、每批最多 4 条，输入估算最多 11,000、输出参数最多 3,000 Token。总预留上限 ¥0.2960，与现有模式共用 UTC 每日 ¥1.00 账本。长评论或多语文本可能使批次不满。预算、权限和运行时间不足会停止新的模型请求。完整服务商费用以账单为准。

Phase K 从点击开始计时，12 分钟后不再开始新的批次，结果到点击后 15 分钟清除。已经进行的网络请求受客户端超时限制。页面只展示证据来源和有界预览；正文、响应和研究结果不写入磁盘。


离线预览默认可使用合成示例。若要展示已获准保留的历史原文，使用 Git 忽略的本机 `Agent/.runtime/phase_k_preview_sources.json`。它将本机存档文件名映射到评论 ID 及三项模拟分析标签（反馈类型、品牌、型号）。预览会跳过过期存档。清单不含原文，正式研究页不读取它。
