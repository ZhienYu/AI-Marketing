# AI-Marketing

## 项目目标

- 学习 GitHub、Git 和基础网页开发知识
- 学习使用 ChatGPT、Codex 等 AI 工具辅助开发
- 搭建个人作品集网站
- 开发一个基于 AI 的海外市场调研 Agent
- 探索如何利用 AI 解决真实商业问题
- 学习 AI 产品从需求分析到开发、部署及用户验证的完整流程

## 项目路线图

### 阶段 0：搭建开发基础（10月12日—10月25日）

- 学习 GitHub 和 Git 的基础操作
- 了解域名、DNS、服务器和 HTTPS
- 搭建基础开发环境
- 部署第一个网页

### 阶段 1：个人网站开发（10月26日—11月8日）

- 学习撰写产品需求文档（PRD）
- 开发个人作品集网站
- 展示个人经历和实践项目

### 阶段 2：AI 海外市场调研 Agent（11月9日—11月29日）

- 学习调用大语言模型 API
- 探索海外消费者评论的数据采集方法
- 使用 AI 分析消费者痛点与竞争产品
- 自动生成市场调研报告
- 部署可供用户体验的 AI 应用

### 阶段 3：用户测试与产品优化（11月30日—12月20日）

- 邀请真实用户体验 AI Agent
- 收集用户反馈
- 根据反馈优化产品功能
- 总结项目成果
