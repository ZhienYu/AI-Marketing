## 2. 本周学到的知识
- Git 是版本控制工具，用于记录文件的修改历史。
- GitHub 是在线托管和管理代码的平台。
- Repository 是用于存放项目文件的仓库。
- Git Clone 可以将远程仓库复制到本地电脑。
- VS Code 可以用来编辑和管理项目文件。
